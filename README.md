Hola, bienvenidos a mi repo!
Aca encontraran el challenge que me pidieron, el mismo esta realizado con selenium y java para lo que es la parte de FrontEnd y RestAssured con java para lo que es la parte de Backend.

Pueden descargar el proyecto y ejecutarlo mediante el comando mvn clean test o sino directamente lo abren con un IDE. En mi caso lo realicé con Intellij.

- Para su ejecucion usar el comando de maven:

    mvn clean test

Para ver los reportes, ejecuta los test y los resultados se veran en un directorio ( allure-results). 
Ejecutar el comando allure open y presiona enter, este comando inicia un servidor local para mostrar el informe en tu navegador predeterminado.
